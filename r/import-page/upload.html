What this import does

Download the template (XLSX)

  • Rows are matched on the item code. A code that already exists is updated; one that does not is created. Nothing is ever deleted by an import, and an item missing from the file is left alone.

  • Every row posts together. Nothing appears in the item master until all of them have. If you would rather post the good rows and deal with the rest afterwards, that is a choice you make at the review stage against a count.

  • The file is not kept. It is staged while you work through these stages and deleted after 7 days. The records it creates are what survives — to keep the vendor's own document, attach it to the rate contract instead.
