{% comment %} templates/vendors/_sections.html Four things the server decides that the browser cannot. 1. Which sections exist. A section the signed-in user may not read is not rendered closed, it is not rendered at all — x-show renders the markup and hides it, so a collapsed panel is not a permission boundary and the landed-cost breakdown behind one is in the page source of everybody who can load the page. 2. Which section starts open. A section holding a bound form with errors is rendered open, because the alternative is a user pressing Save against a shut panel and being told nothing. x-cloak goes on only where the panel starts closed: on one that starts open it holds the panel hidden until Alpine boots, which is the exact flash x-cloak exists to prevent. 3. The panel ids. Rendered in a loop they take the record key and the section slug, or the second header's aria-controls points at the first panel and every row opens the same section. 4.
