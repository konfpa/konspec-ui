{% comment %} The out-of-band half, and only on a swap. htmx strips an oob element out of a response and writes it into the node it names; on a full page load it is ordinary markup and would print the sentence on screen. {% endcomment %} {% if request.htmx %} Page {{ page_obj.number }} of {{ page_obj.paginator.num_pages }}, showing {{ page_obj.start_index }} to {{ page_obj.end_index }} of {{ page_obj.paginator.count }} orders {% endif %} {% comment %} orders/views.py def register(request): orders = Order.objects.select_related('vendor').order_by('-raised_on') paginator = Paginator(orders, 25) page_obj = paginator.get_page(request.GET.get('page')) template = ('orders/_register.html' if request.htmx else 'orders/register.html') return render(request, template, { 'page_obj': page_obj, 'page_range': paginator.get_elided_page_range( page_obj.number, on_each_side=1, on_ends=1), 'base_query': urlencode({'q': request.GET.get('q', ''), 'size': request.GET.get('size', '25')}), }) get_page rather than page: it takes a page number that is not a number, or is past the end, and returns the first or last page instead of raising, which is what a bookmarked ?page=98 on a register that has since shrunk needs. The swap returns the partial and the page returns the shell around it, which is the only reason the shell survives its own swaps. Return the page template to a swap and the response carries a second shell, which htmx drops inside the first one along with a duplicate of every id in it. {% endcomment %}
